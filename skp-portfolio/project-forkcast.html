ForkCast

Live

Turns decision text into flowcharts, and flags what the text leaves unsaid.

Input
A written decision, one line to a multi-page SOP
Output
Parse report · diagram · assumption ledger · the open question
Export
SVG or Mermaid
Stack
Next.js 15 · TypeScript · hand-built SVG · no backend

01

The problem

Decisions written as prose hide their branches, loops and unstated steps.

02

What I built

Paste a written decision and get a flowchart back: gates, actors, loops and dead ends. Paths the text implies but never states are drawn dashed. An assumption ledger lists what had to be guessed, and the tool names the one question the text leaves open.
