01

What it is

A software cryptographic module: the part of FortiClient that performs its cryptography. A FIPS 140-3 validation shows that it does what the standard requires. An accredited lab tests it, and the Cryptographic Module Validation Program, run jointly by NIST and the Canadian Centre for Cyber Security, reviews that evidence before listing the module as validated.

02

My part

  • Scoping. Agreeing what the validation covers, before anyone tests anything.
  • The boundary. Defining what is inside the module and what is not.
  • Key-management flows. How keys flow through the module.
  • Approved-mode checks. Confirming the module behaves as the standard expects when running in its approved mode.

03

What was produced

The evidence the lab examined and NIST validated, at Security Level 1 for a software module.

04

Where it stands

Validated on 17 August 2026 and listed publicly as CMVP certificate #5493.
